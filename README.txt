НЕОНОВЫЙ РОЙ — браузерная игра на JavaScript
=============================================

ЗАПУСК
1. Открыть папку NeonGame в VS Code (File -> Open Folder).
2. Двойной клик по index.html — игра откроется в браузере (Chrome или Edge).
3. Пишем код в game.js -> Ctrl+S -> в браузере F5.

НИЧЕГО УСТАНАВЛИВАТЬ НЕ НУЖНО. Сервер тоже не нужен.

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
   F12 -> вкладка Console. Красная строка = ошибка, справа — файл и номер строки.

ЧТО ГДЕ ЛЕЖИТ
  index.html — страница: табло, холст <canvas>, экран GAME OVER (готово)
  style.css  — неоновое оформление страницы (готово)
  game.js    — НАША игра: пишем сами
